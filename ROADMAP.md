# BingeSaga roadmap

This roadmap describes intended directions, not delivery commitments.

## Next

- [ ] Add frontend unit and component tests for authentication flows and API error states.
- [ ] Add test coverage reporting and a minimum coverage target to CI.
- [ ] Make the frontend API base URL configurable through `VITE_API_URL`.
- [ ] Provide a self-contained local Docker Compose profile with PostgreSQL and Redis.

## Later

- [ ] Improve accessibility coverage, including keyboard navigation and contrast checks.
- [ ] Add richer diary filtering, sorting, and export options.
- [ ] Expand social features such as follows, activity feeds, and curated lists.
- [ ] Add observability dashboards and production health checks.
